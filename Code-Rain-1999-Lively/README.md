# Code Rain 1999 — Lively Wallpaper

## Sources
- Character inventory: Carl Newton, frame-by-frame analysis of the 1999 opening — carlnewton.github.io/digital-rain-analysis
- Cell model, timing and "Authentic" palette: matrix.watch, Authentic style description
- Glyphs rendered from Noto Sans JP Bold (SIL OFL) and DejaVu Sans Mono Bold (Bitstream Vera license)

## Contribution by E11iot
- Concept and direction of the wallpaper
- Observations from the film: one grid with equal-size glyphs, twin strings in neighbouring columns, single glyphs appearing in gaps, leaders that rewrite or only re-brighten, persistent trails
- Colour measurements from film stills and hand-tuned "Film" defaults for every setting
